MSD Customer Support Chatbot MVP

A smarter, faster support experience for MSD customers.

This MVP is designed as a clean customer support chatbot and agent ticketing system for MSD-style service delivery. It gives health facilities and guests a simple way to ask questions, search help topics, create tickets, continue unresolved cases, and connect with support agents when the chatbot is not enough.

🤖

Customer Chatbot

Users can ask questions, search related topics live, access FAQs, and create support tickets when their issue needs human help.

🎫

Ticketing System

Each query can become a ticket, allowing the user to continue from the last message until the issue is solved.

👨‍💻

Agent Inbox

Agents can manage New, Active, Resolved, and All tickets, with a maximum active capacity to avoid overload.

📝

Open New Ticket

Customers can directly start a new support request from the chatbot homepage.

🧠

MediAssist AI

Coming in Phase Two: an AI support assistant for fast MSD service guidance and self-service answers.

🌓

MSD Dark & Light Themes

The whole MVP supports theme switching between a dark support-console look and a clean white-and-blue MSD light interface.
